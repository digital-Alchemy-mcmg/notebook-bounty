# SDNA Python Notebook Bounty — Island Repository

This repository is the starting point for an independent Python notebook extraction bounty.

## Purpose

Participants will develop their **own** Python/Jupyter notebooks to extract source-grounded atomic evidence blurbs from synthetic candidate documents. Each blurb must preserve a traceable reference to its source.

## Participation model

- The operator maintains this repository as the shared starting point.
- Approved participants acknowledge the bounty rules, fork the repository, and work independently in their own GitHub Codespaces or equivalent Python environments.
- Participants submit their notebook, extraction output, and execution evidence for evaluation.
- The operator supplies the bounty brief and synthetic documents before participation begins.

## Scope

The bounty covers Python document extraction only. It does **not** include Spark classification, Google integrations, MARA pipeline stages, or the operator's internal architecture.
